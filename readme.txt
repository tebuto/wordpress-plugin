== Beschreibung ==
Dieses Plugin integriert Tebuto mit WordPress. Es ermöglicht die Synchronisation von [bestimmten Funktionen] aus Tebuto direkt in deine WordPress-Website.

**Hinweis:** Für die Nutzung des Plugins ist ein kostenloser oder kostenpflichtiger Tebuto-Account erforderlich. Anmeldung unter: [Tebuto Website](https://tebuto.com).

== Installation ==
1. Lade das Plugin herunter und installiere es über den WordPress-Plugin-Manager.
2. Gehe zu den Plugin-Einstellungen und verbinde dein Tebuto-Konto.
3. Konfiguriere die gewünschten Einstellungen und Funktionen.

== Häufige Fragen ==
= Ist ein Tebuto-Account notwendig? =
Ja, um dieses Plugin nutzen zu können, benötigst du einen Tebuto-Account. 

= Ist das Plugin kostenlos? =
Ja, das Plugin selbst ist kostenlos. Für einige Funktionen in Tebuto könnten Gebühren anfallen.
